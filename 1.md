## 1. Introduction to OOP

### What is OOP?

**Object-Oriented Programming (OOP)** is a programming approach where a program is designed around **objects** rather than only functions and procedures.

An **object** represents something that has:

- **Data / state** — what the object contains
- **Behavior / functions** — what the object can do

For example, a `Student` object can have:

```text
Data:
    name
    rollNo
    marks

Behavior:
    display()
    calculateGrade()
```

### Why OOP?

Traditional procedural programming focuses mainly on:

```text
Functions → manipulate data
```

OOP focuses on:

```text
Objects → contain data + functions
```

This makes large programs easier to organize, maintain, reuse, and extend.

---

## 2. Main Concepts of OOP

### 2.1 Class

A **class** is a user-defined data type that acts as a blueprint for objects.

Example:

```cpp
class Student {
public:
    string name;
    int rollNo;

    void display() {
        cout << name << " " << rollNo;
    }
};
```

The class itself is a blueprint. Memory for its non-static data members is generally associated with objects created from it.

---

### 2.2 Object

An **object** is an instance of a class.

```cpp
Student s1;
Student s2;
```

Here `s1` and `s2` are two different objects of `Student`.

Each object has its own non-static data members.

---

### 2.3 Encapsulation

**Encapsulation** means combining data and functions into a single unit, usually a class, and controlling access to that data.

```cpp
class BankAccount {
private:
    double balance;

public:
    void deposit(double amount) {
        balance += amount;
    }
};
```

`balance` cannot normally be accessed directly from outside the class.

---

### 2.4 Abstraction

**Abstraction** means exposing the important interface while hiding unnecessary implementation details.

Example:

```cpp
account.deposit(5000);
```

The user does not need to know every internal operation performed by `deposit()`.

---

### 2.5 Inheritance

Inheritance allows one class to acquire properties and behavior from another class.

```cpp
class Animal {
public:
    void eat() {
        cout << "Eating";
    }
};

class Dog : public Animal {
};
```

`Dog` can use the inherited `eat()` function.

---

### 2.6 Polymorphism

**Polymorphism** means "many forms."

A common example is function overloading:

```cpp
void add(int a, int b);
void add(double a, double b);
```

The same function name can behave differently depending on the arguments.

---

### 2.7 Dynamic Binding

Dynamic binding means the function to be executed can be determined at runtime. It is associated with runtime polymorphism, typically through virtual functions.

This topic may be covered more deeply later.

---

### 2.8 Message Passing

Objects can communicate by calling each other's functions.

```cpp
student.display();
```

The object `student` receives a request to perform `display()`.

# 4. Basic C++ Input and Output

C++ uses streams for input and output.

The most commonly used objects are:

```cpp
cin
cout
```

They are provided through the `<iostream>` header.

```cpp
#include <iostream>
using namespace std;
```

---

## 4.1 `cout`

`cout` is used to send output to the standard output stream.

```cpp
cout << "Hello";
```

Multiple values can be printed:

```cpp
int age = 20;

cout << "Age = " << age;
```

### `<<` operator

The `<<` operator is called the **insertion operator** when used with `cout`.

```cpp
cout << value;
```

---

## 4.2 `cin`

`cin` is used to read input from the standard input stream.

```cpp
int age;

cin >> age;
```

### `>>` operator

The `>>` operator is called the **extraction operator** when used with `cin`.

```cpp
cin >> age;
```

---

## 4.3 Multiple Inputs

```cpp
int a, b;

cin >> a >> b;
```

If the user enters:

```text
10 20
```

then:

```text
a = 10
b = 20
```

---

## 4.4 Multiple Outputs

```cpp
cout << "A = " << a << ", B = " << b;
```

---

## 4.5 `endl`

`endl` inserts a newline and flushes the output stream.

```cpp
cout << "Hello" << endl;
cout << "World";
```

Output:

```text
Hello
World
```

For simply moving to the next line, `'\n'` is often more efficient:

```cpp
cout << "Hello\n";
```

## 4.6 Basic Input/Output Program

```cpp
#include <iostream>
using namespace std;

int main() {
    string name;
    int age;

    cout << "Enter name: ";
    cin >> name;

    cout << "Enter age: ";
    cin >> age;

    cout << "Name: " << name << endl;
    cout << "Age: " << age << endl;

    return 0;
}
```

> Note: `cin >> name` reads only up to whitespace. Reading complete lines with `getline()` is a related topic.

# 9. Access Specifiers

C++ classes commonly use:

```text
public
private
protected
```

For the current syllabus, focus especially on `public` and `private`.

### `public`

Members can be accessed from outside the class.

```cpp
class A {
public:
    int x;
};
```

```cpp
A obj;
obj.x = 10;
```

### `private`

Members cannot be accessed directly from outside the class.

```cpp
class A {
private:
    int x;
};
```

This will not be allowed:

```cpp
A obj;
obj.x = 10;   // error
```

---

## Default Access Difference

This is a very important exam point:

### Class

Members are **private by default**.

```cpp
class A {
    int x;  // private
};
```

### Struct

Members are **public by default**.

```cpp
struct A {
    int x;  // public
};
```

You can explicitly change the access specifier.

---

# 10. Structure vs Class

Both `struct` and `class` can contain:

- Data members
- Member functions
- Constructors
- Access specifiers
- Static members
- etc.

The main basic difference is the **default access level**.

| Feature | `class` | `struct` |
|---|---|---|
| Default member access | private | public |
| Can contain functions? | Yes | Yes |
| Can use public/private/protected? | Yes | Yes |
| Can create objects? | Yes | Yes |
| Supports inheritance? | Yes | Yes |

Example:

```cpp
class A {
    int x;  // private
};
```

versus:

```cpp
struct B {
    int x;  // public
};
```

---

# 11. Union

A **union** is a user-defined type in which its non-static data members share the same memory location.

Example:

```cpp
union Data {
    int i;
    float f;
    char c;
};
```

An object can be created:

```cpp
Data d;
```

The important idea is:

```text
union
 ├── int i
 ├── float f
 └── char c
       ↓
   shared storage
```

Because the members share storage, a union is useful when only one of several representations needs to be stored at a time.

Example:

```cpp
d.i = 10;
```

Writing another member changes the stored representation:

```cpp
d.f = 3.14;
```

You should not think of a union as storing all its members independently like a normal class object.

---

# 12. Enumeration (`enum`)

An enumeration defines a type consisting of a set of named constants.

Example:

```cpp
enum Day {
    MONDAY,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY
};
```

You can create a variable:

```cpp
Day today = MONDAY;
```

By default, enumerators typically receive successive integer values beginning at `0`.

So:

```text
MONDAY    = 0
TUESDAY   = 1
WEDNESDAY = 2
...
```

You can also specify values:

```cpp
enum Status {
    SUCCESS = 1,
    FAILURE = 0
};
```

### Why use enum?

Instead of:

```cpp
int day = 1;
```

you can write:

```cpp
Day day = TUESDAY;
```

The code becomes more meaningful.

---

# 13. Class vs Structure vs Union vs Enum

This is a common comparison question.

| Feature | Class | Struct | Union | Enum |
|---|---|---|---|---|
| Main purpose | Objects + encapsulation | Group data/objects | Share storage | Named constants |
| Member functions | Yes | Yes | Limited language rules apply | No ordinary data members |
| Default access | Private | Public | Public | N/A |
| Data storage | Separate members | Separate members | Shared storage | Represents enumerated values |
| Objects/variables | Yes | Yes | Yes | Variables of enum type |
| Typical use | OOP design | Simple data structures | Memory-efficient alternatives | Fixed set of choices |

> **Exam shortcut:**  
> Class → blueprint for objects  
> Struct → similar to class, public by default  
> Union → members share storage  
> Enum → named set of values

# 14. Inline Member Functions

An **inline function** is a function for which the compiler is permitted to perform inline substitution at suitable call sites.

Example:

```cpp
class Calculator {
public:
    inline int square(int x) {
        return x * x;
    }
};
```

A function defined inside a class definition is implicitly inline (subject to the usual C++ rules).

```cpp
class Calculator {
public:
    int square(int x) {
        return x * x;
    }
};
```

This function is inline by definition.

---

# 15. Non-inline Member Functions

A member function can be declared inside the class and defined outside it.

```cpp
class Student {
public:
    void display();
};

void Student::display() {
    cout << "Hello";
}
```

Here:

```cpp
void display();
```

is the declaration.

And:

```cpp
void Student::display() {
}
```

is the definition.

The `::` is the **scope resolution operator**.

---

# 16. Inline vs Non-inline Member Functions

| Inline | Non-inline |
|---|---|
| Can be defined inside the class | Often defined outside the class |
| Suitable for small functions | Suitable for larger functions |
| Compiler may substitute function body at call sites | Normal function call mechanism |
| Reduces function-call overhead when actually inlined | Function-call overhead may apply |

### Important misconception

`inline` is a **request/specification**, not a command forcing the compiler to substitute the function body.

# 17. Static Data Members

A normal data member belongs separately to each object.

A **static data member belongs to the class**, so there is one shared member for the class rather than one separate copy per object.

Example:

```cpp
class Student {
public:
    static int count;
};

int Student::count = 0;
```

Then:

```cpp
Student s1;
Student s2;

Student::count = 2;
```

Both objects refer to the same static data member.

---

## Why static data members?

Suppose you want to keep track of the number of objects created.

```cpp
class Student {
public:
    static int count;

    Student() {
        count++;
    }
};

int Student::count = 0;
```

Then:

```cpp
Student s1;
Student s2;
Student s3;

cout << Student::count;
```

Output:

```text
3
```

The key idea:

```text
s1 ─┐
s2 ─┼──→ Student::count
s3 ─┘
```

One shared variable.

---

# 18. Static Member Functions

A **static member function belongs to the class rather than to a particular object**.

Example:

```cpp
class Test {
public:
    static void show() {
        cout << "Hello";
    }
};
```

It can be called using the class name:

```cpp
Test::show();
```

### Important rule

A static member function does not have a `this` pointer because it is not called for a particular object.

Therefore, it cannot directly access non-static data members.

Example:

```cpp
class Test {
    int x;

public:
    static void show() {
        // cout << x;  // Error
    }
};
```

But it can directly access static members.

```cpp
class Test {
    static int x;

public:
    static void show() {
        cout << x;
    }
};

int Test::x = 10;
```

---

# 19. Static Data Member vs Static Member Function

| Static Data Member | Static Member Function |
|---|---|
| One shared variable for the class | Function belonging to class |
| Shared by all objects | Can be called using class name |
| Requires definition/initialization outside class in traditional cases | Cannot directly access non-static members |
| Accessed as `ClassName::member` | Called as `ClassName::function()` |

# 20. Procedural Programming

Procedural programming organizes programs primarily around **functions/procedures**.

Typical flow:

```text
Input
 ↓
Functions
 ↓
Data processing
 ↓
Output
```

Example:

```cpp
int add(int a, int b) {
    return a + b;
}

int main() {
    cout << add(10, 20);
}
```

The emphasis is on the procedures/functions that operate on data.

---

# 21. Object-Oriented Programming

OOP organizes a program around objects and classes.

Example:

```cpp
class Calculator {
public:
    int add(int a, int b) {
        return a + b;
    }
};
```

```cpp
Calculator c;
cout << c.add(10, 20);
```

The emphasis is on objects containing state and behavior.

---

# 22. Procedural vs OOP

| Procedural Programming | OOP |
|---|---|
| Function-oriented | Object-oriented |
| Data and functions are often separate | Data and functions are combined in classes |
| Top-down approach is commonly emphasized | Bottom-up approach is commonly emphasized |
| Less natural data hiding | Strong data hiding using access control |
| Reuse through functions/modules | Reuse through classes, inheritance, composition, etc. |
| Good for smaller/simple tasks | Particularly useful for larger systems |
| Examples: C, Pascal | C++, Java, C# |

> These are broad conceptual differences; modern languages can support multiple styles.

# 23. Features of C++ Input/Output Streams

A **stream** can be thought of as a flow of data.

```text
Input:
Keyboard → cin → Program

Output:
Program → cout → Screen
```

C++ stream-based I/O provides:

### 23.1 Type-safe I/O

The stream operators work with many C++ data types.

```cpp
int x;
double y;
string name;

cin >> x >> y >> name;
```

### 23.2 Formatting

Output can be formatted using manipulators such as:

```cpp
endl
setw()
setprecision()
fixed
```

Some manipulators require:

```cpp
#include <iomanip>
```

### 23.3 Operator-based syntax

Input:

```cpp

```

Output:

```cpp
cout << x;
```

### 23.4 Error/state handling

Streams maintain state information such as:

- good state
- end-of-file
- fail state
- bad state

Common functions include:

```cpp
cin.fail()
```

Important standard streams include:

| Stream | Purpose |

| `cerr` | Standard error output |
| `clog` | Standard logging/error stream |

# 24. Complete Example Combining Core Concepts

```cpp
#include <iostream>
#include <string>
using namespace std;

class Student {
private:
    int rollNo;
    string name;

public:
    static int count;

    Student(int r, string n) {
        rollNo = r;
        name = n;
        count++;
    }

    void display() {
        cout << "Roll No: " << rollNo << endl;
        cout << "Name: " << name << endl;
    }

    static void showCount() {
        cout << "Students: " << count << endl;
    }
};

int Student::count = 0;

int main() {
    Student s1(101, "Aman");
    Student s2(102, "Riya");

    s1.display();
    s2.display();

    Student::showCount();

    return 0;
}
```

This example combines:

- Class
- Objects
- Private members
- Public member functions
- Static data member
- Static member function
- `cout`
- `endl`
- Scope resolution operator
