# 1. What Is a Pointer?

A **pointer is a variable that stores the memory address of another variable.**

```cpp
int x = 10;
int *p = &x;
```

Here:

```text
x = 10
p = address of x
*p = value stored at that address = 10
```

Important operators:

```cpp
&x   // address of x
*p   // value at the address stored in p
```

Example:

```cpp
int x = 10;
int *p = &x;

cout << x << endl;    // 10
cout << &x << endl;   // address
cout << p << endl;    // address
cout << *p << endl;   // 10
```

### Mental model

```text
        ┌──────────────┐
x       │      10      │
        └──────────────┘
              ↑
              │
             p
        stores address
```

# 2. Pointer Declaration

Syntax:

```cpp
dataType *pointerName;
```

Examples:

```cpp
int *p;
float *q;
char *c;
double *d;
```

The pointer's type tells C++ what type of object it points to.

```cpp
int x = 10;
int *p = &x;
```

`p` is a pointer to `int`.

# 3. Initialization of Pointers

Never use an uninitialized pointer.

Bad:

```cpp
int *p;
*p = 10;
```

`p` contains an unpredictable address.

Better:

```cpp
int *p = nullptr;
```

or:

```cpp
int x = 10;
int *p = &x;
```

---

# 4. Null Pointer

A null pointer intentionally points to no object.

Modern C++:

```cpp
int *p = nullptr;
```

Check:

```cpp
if (p == nullptr) {
    cout << "Pointer is null";
}
```

Do NOT dereference it:

```cpp
*p = 10;    // ERROR / undefined behavior
```

### `nullptr` vs `NULL`

Prefer:

```cpp
int *p = nullptr;
```

over older:

```cpp
int *p = NULL;
```

`nullptr` is the C++ null pointer literal.

---

# 5. Pointer Dereferencing

Dereferencing means accessing the object through its pointer.

```cpp
int x = 50;
int *p = &x;

cout << *p;
```

Output:

```text
50
```

You can also modify the original:

```cpp
*p = 100;

cout << x;   // 100
```

Because `p` points to `x`.

# 6. Pointer Arithmetic

Pointer arithmetic allows a pointer to move between elements of an array.

```cpp
int arr[4] = {10, 20, 30, 40};

int *p = arr;
```

Since `arr` represents the address of its first element:

```text
p → arr[0]
```

Then:

```cpp
p + 1
```

points to the next `int`, not simply one byte later.

For an `int`, conceptually:

```text
p + 1 → next int
p + 2 → two ints ahead
```

Example:

```cpp
cout << *(p + 2);
```

Output:

```text
30
```

Equivalent array notation:

```cpp
arr[2]
```

and:

```cpp
*(arr + 2)
```

access the same element.

## Important pointer arithmetic

If:

```cpp
int *p;
```

then:

```cpp
p + 1
p - 1
p++
p--
```

move by the size of the pointed-to type.

For an array:

```cpp
arr[i] == *(arr + i)
```

This is one of the most important pointer/array relationships.

---

# 7. Pointer Addition Does NOT Mean Byte Addition

Suppose:

```cpp
int arr[5];
int *p = arr;
```

If an `int` occupies 4 bytes on the system, then conceptually:

```text
p       → address A
p + 1   → A + 4 bytes
p + 2   → A + 8 bytes
```

You normally do not manually calculate those byte offsets; C++ handles the scaling according to the pointed-to type.

# 8. Pointer to Pointer

A **pointer to pointer** stores the address of another pointer.

```cpp
int x = 10;

int *p = &x;

int **q = &p;
```

Relationship:

```text
x = 10
↑
p = address of x
↑
q = address of p
```

Access:

```cpp
cout << x;     // 10
cout << *p;    // 10
cout << **q;   // 10
```

Think:

```text
q   → p   → x
            10
```

### Why use pointer-to-pointer?

It is useful when a function needs to modify a pointer itself, and in structures such as dynamic linked data structures.

# 9. Dangling Pointer

A **dangling pointer** is a pointer that refers to an object whose lifetime has ended.

Example:

```cpp
int *p;

{
    int x = 10;
    p = &x;
}

// x no longer exists here
```

Now `p` is dangling.

Another common case:

```cpp
int *p = new int(10);

delete p;

// p is now dangling
```

Better:

```cpp
delete p;
p = nullptr;
```

Mental model:

```text
Before delete:

p ─────→ [10]

After delete:

p ─────→ [destroyed memory]
```

---

# 10. Wild Pointer

A **wild pointer** is an uninitialized pointer whose value is indeterminate.

```cpp
int *p;

cout << *p;    // dangerous
```

The pointer has not been assigned a valid address.

Avoid:

```cpp
int *p;
```

Use:

```cpp
int *p = nullptr;
```

---

# 11. Null Pointer Assignment / Null Pointer Dereference

A null pointer is intentionally assigned no valid object:

```cpp
int *p = nullptr;
```

The problem occurs if you dereference it:

```cpp
cout << *p;
```

That is invalid.

Remember:

```text
nullptr = safe state for "points to nothing"

*p when p == nullptr = NOT safe
```

---

# 12. Three Pointer Problems

| Type | Meaning | Example |
|---|---|---|
| Wild | Never initialized | `int *p;` |
| Null | Intentionally points to nothing | `int *p = nullptr;` |
| Dangling | Points to an object that no longer exists | `delete p;` then use `p` |

Easy memory trick:

```text
WILD     → never had a proper target
NULL     → intentionally no target
DANGLING → target used to exist, but doesn't anymore
```

# 13. Classes Containing Pointers

A class can have pointer data members.

```cpp
class Student {
private:
    int *marks;

public:
    Student(int m) {
        marks = new int(m);
    }

    void display() {
        cout << *marks;
    }

    ~Student() {
        delete marks;
    }
};
```

Here:

```cpp
int *marks;
```

stores an address.

The constructor dynamically allocates memory:

```cpp
marks = new int(m);
```

The destructor releases it:

```cpp
delete marks;
```

### Important

When a class owns dynamically allocated memory, you must think about:

```text
Constructor → acquire memory
Destructor  → release memory
Copying     → potentially dangerous
```

---

# 14. Why Pointer Members Can Be Dangerous

Consider:

```cpp
class A {
public:
    int *p;
};
```

If two objects end up pointing to the same dynamically allocated memory, modifying or deleting through one object can affect the other.

Shallow copying can produce:

```text
Object A ───┐
            ├──→ same memory
Object B ───┘
```

Then:

```cpp
delete A.p;
```

can leave `B.p` dangling.

This is why classes managing raw dynamic memory require careful copy/destruction design.


```cpp
p->display();
```

Equivalent:

```cpp
(*p).display();
```

The arrow operator:

```cpp
->
```

is used when accessing a member through an object pointer.

# 17. `this` Pointer

Every non-static member function has access to a special pointer called:

```cpp
this
```

It points to the **current object**.

Example:

```cpp
class Student {
private:
    int marks;

public:
    void setMarks(int marks) {
        this->marks = marks;
    }
};
```

Here:

```cpp
this->marks
```

means the current object's data member.

The parameter:

```cpp
marks
```

and data member:

```cpp
marks
```

have the same name.

So:

```cpp
this->marks = marks;
```

means:

```text
current object's marks = parameter marks
```

---

# 18. Another Use of `this`

`this` can be used to return the current object.

```cpp
class Test {
public:
    Test& getObject() {
        return *this;
    }
};
```

It can also be used when passing the current object to another function.

### Important restriction

A static member function does not have a `this` pointer because it is associated with the class rather than a particular object.

# 21. Pointer vs Reference

Both can refer to another object, but they behave differently.

| Pointer | Reference |
|---|---|
| Stores an address | Alias for an existing object |
| Can be `nullptr` | Ordinary reference is expected to refer to an object |
| Can be changed to point elsewhere | Cannot normally be reseated |
| Uses `*` to dereference | Used like the original variable |
| Pointer arithmetic is possible for suitable pointers | No pointer arithmetic |
| Can be declared without initialization, though unsafe | Normally initialized at declaration |

Example:

```cpp
int x = 10;

int *p = &x;
int &r = x;
```

Access:

```cpp
*p
r
```

Both give:

```text
10
```

# 22. Arrays

An array stores multiple values of the same type in contiguous memory.

```cpp
int arr[5] = {10, 20, 30, 40, 50};
```

Indexes:

```text
arr[0] → 10
arr[1] → 20
arr[2] → 30
arr[3] → 40
arr[4] → 50
```

Important:

```text
First index = 0
Last index = size - 1
```

---

# 23. Array and Pointer Relationship

For:

```cpp
int arr[5];
```

in most expressions:

```cpp
arr
```

converts to a pointer to its first element.

Therefore:

```cpp
arr
```

is closely related to:

```cpp
&arr[0]
```

And:

```cpp
arr[i]
```

is equivalent to:

```cpp
*(arr + i)
```

Example:

```cpp
int arr[3] = {10, 20, 30};

cout << arr[1];
cout << *(arr + 1);
```

Both output:

```text
20
```


Visual representation:

```text
        column
```

Access:


# 25. Processing a 2D Array Inside `main`

```cpp
#include <iostream>
using namespace std;

int main() {
    int matrix[2][3];

    for (int i = 0; i < 2; i++) {
        for (int j = 0; j < 3; j++) {
            cin >> matrix[i][j];
        }
    }

    for (int i = 0; i < 2; i++) {
        for (int j = 0; j < 3; j++) {
            cout << matrix[i][j] << " ";
        }
        cout << endl;
    }
}
```

Pattern:

```text
outer loop → rows
inner loop → columns
```

---

# 26. Multidimensional Arrays Inside a Class

```cpp
class Matrix {
private:
    int arr[2][3];

public:
    void input() {
        for (int i = 0; i < 2; i++) {
            for (int j = 0; j < 3; j++) {
                cin >> arr[i][j];
            }
        }
    }

    void display() {
        for (int i = 0; i < 2; i++) {
            for (int j = 0; j < 3; j++) {
                cout << arr[i][j] << " ";
            }
            cout << endl;
        }
    }
};
```

Usage:

```cpp
Matrix m;

m.input();
m.display();
```

# 49. Pointer to Data Member

This is a more advanced pointer concept.

A **pointer to data member** stores information that identifies a non-static data member of a class.

Example:

```cpp
class Student {
public:
    int marks;
};
```

Create a pointer to the member:

```cpp
int Student::*ptr = &Student::marks;
```

Now:

```cpp
Student s;
s.marks = 90;

cout << s.*ptr;
```

Output:

```text
90
```

For an object pointer:

```cpp
Student *p = &s;

cout << p->*ptr;
```

### Important operators

For an object:

```cpp
object.*pointerToMember
```

For an object pointer:

```cpp
pointer->*pointerToMember
```

Do not confuse this with an ordinary pointer:

```cpp
int *p;
```

A pointer to data member is specifically tied to a class member.

# 55. Pointer Safety Checklist

Before dereferencing a pointer, ask:

```text
1. Has it been initialized?
2. Does it point to a valid object?
3. Has that object already been destroyed?
4. Is it nullptr?
5. Am I accessing within a valid array/object?
```

Examples of unsafe situations:

```cpp
int *p;             // wild
*p = 10;
```

```cpp
int *p = nullptr;   // null
*p = 10;
```

```cpp
int *p = new int;
delete p;           // dangling
*p = 10;
```

# 70. Important Pointer Cheat Sheet

```cpp
int x = 10;

int *p = &x;
int **q = &p;
int &r = x;
```

```text
&x  → address of x
p   → address of x
*p  → value of x

&q  → address of q
*q  → p
**q → x's value

r   → alias of x
```

Object:

```cpp
Student s;
Student *p = &s;
```

```cpp
s.display();       // object
p->display();      // object pointer
(*p).display();    // same
```
