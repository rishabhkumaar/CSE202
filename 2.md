# C++ Unit I — Functions, Friends, References, and Recursion

## 1. Functions

A **function** is a named block of code that performs a specific task.

```cpp
int add(int a, int b) {
    return a + b;
}
```

### Function parts

```cpp
returnType functionName(parameters) {
    // body
    return value;
}
```

- **Return type:** type of value returned.
- **Function name:** identifies the function.
- **Parameters:** variables in the function definition.
- **Arguments:** actual values supplied during a call.
- **Return statement:** sends a value back to the caller.

### Declaration, definition, call

```cpp
int add(int, int);             // declaration

int add(int a, int b) {        // definition
    return a + b;
}

int x = add(10, 20);            // call
```

Mental model:

```text
Declaration → function exists
Definition  → what it does
Call        → execute it
```

---

# 2. Default Parameters / Arguments

A **default argument** is a value used automatically when the caller does not supply that argument.

```cpp
void greet(string name = "User") {
    cout << "Hello " << name;
}
```

```cpp
greet();          // Hello User
greet("Riya");    // Hello Riya
```

## Multiple defaults

```cpp
int add(int a, int b = 10, int c = 20) {
    return a + b + c;
}
```

```cpp
add(5);          // 35
add(5, 15);      // 40
add(5, 15, 25);  // 45
```

### Important rule

Once a parameter has a default argument, parameters to its **right** must also have defaults.

Correct:

```cpp
void fun(int a, int b = 10, int c = 20);
```

Incorrect:

```cpp
void fun(int a = 10, int b);
```

Think:

```text
Default arguments generally go from RIGHT → LEFT.
```

### Declaration and definition

Normally specify the default in the declaration:

```cpp
void display(int x = 10);

void display(int x) {
    cout << x;
}
```

Do not repeat the default in the definition in the same scope.

---

# 3. Inline Functions

An **inline function** is a function for which the compiler is permitted to perform inline substitution at suitable call sites.

```cpp
inline int square(int x) {
    return x * x;
}
```

Conceptually:

```cpp
square(5)
```

may be substituted with the corresponding operations at the call site.

### Important

`inline` does **not guarantee** that the compiler will inline the function.

Use inline functions mainly for small functions where inline substitution may be useful.

A member function defined inside a class definition is implicitly inline:

```cpp
class Math {
public:
    int square(int x) {
        return x * x;
    }
};
```

# 4. Manipulator Functions

Manipulators control or format C++ input/output streams.

Common ones:

```cpp
endl
setw()
setprecision()
fixed
left
right
```

Formatting manipulators such as `setw()` and `setprecision()` commonly require:

```cpp
#include <iomanip>
```

## `endl`

```cpp
cout << "Hello" << endl;
```

It inserts a newline and flushes the stream.

For just a newline:

```cpp
cout << "Hello\n";
```

is often preferable.

## `setw()`

Sets the width for the **next formatted field**.

```cpp
cout << setw(10) << 25;
```

Useful for tables.

```cpp
cout << setw(10) << "Name"
     << setw(10) << "Marks" << endl;
```

`setw()` normally affects only the next field.

## `setprecision()`

Controls floating-point precision.

```cpp
cout << setprecision(4) << 3.1415926;
```

Without `fixed`, this generally controls significant digits.

## `fixed`

Use with `setprecision()` to specify digits after the decimal point:

```cpp
cout << fixed << setprecision(2) << 3.1415926;
```

Output:

```text
3.14
```

## `left` and `right`

Control alignment within a field:

```cpp
cout << setw(10) << left << "Hello";
cout << setw(10) << right << "Hello";
```

# 5. Function Overloading

**Function overloading** means having multiple functions with the same name but different parameter lists.

```cpp
int add(int a, int b) {
    return a + b;
}

double add(double a, double b) {
    return a + b;
}
```

The compiler chooses based on the arguments.

## Valid ways to overload

### Different number of parameters

```cpp
void show(int a);
void show(int a, int b);
```

### Different parameter types

```cpp
void show(int a);
void show(double a);
```

### Different order of parameter types

```cpp
void show(int a, double b);
void show(double a, int b);
```

## Return type alone cannot overload

Invalid:

```cpp
int fun(int x);
double fun(int x);
```

The parameter lists are identical, so the return type alone is insufficient.

# 6. Scope Rules

**Scope** means the region of a program where a name can be accessed.

Important scopes:

- Local/function scope
- Block scope
- Global/namespace scope
- Class scope

## Local scope

```cpp
void fun() {
    int x = 10;
}
```

`x` is accessible only within its relevant local scope.

## Block scope

```cpp
int main() {
    int x = 10;

    {
        int y = 20;
        cout << x << y;
    }

    // y cannot be used here
}
```

## Global variable

```cpp
int x = 100;

int main() {
    cout << x;
}
```

## Local hides global

```cpp
int x = 100;

int main() {
    int x = 50;

    cout << x;    // 50
}
```

## Scope resolution operator

```cpp
int x = 100;

int main() {
    int x = 50;

    cout << x << endl;   // 50
    cout << ::x << endl; // 100
}
```

`::x` refers to the global `x`.

It is also used to define class member functions outside their class:

```cpp
class Student {
public:
    void display();
};

void Student::display() {
    cout << "Hello";
}
```

# 7. Friend of a Class

A **friend** is a function or class given permission to access private and protected members of another class.

Two forms:

```text
Friend function
Friend class
```

---

# 8. Friend Function

A friend function is **not a member function**, but it can access private/protected members.

```cpp
class Box {
private:
    int length;

public:
    Box() {
        length = 10;
    }

    friend void show(Box b);
};

void show(Box b) {
    cout << b.length;
}
```

Call it like a normal function:

```cpp
Box b;
show(b);
```

Not:

```cpp
b.show();    // wrong: show is not a member
```

### Important facts

- Declared with `friend` inside the class.
- Not a member of the class.
- Can access private and protected members.
- Has no `this` pointer.
- Called like an ordinary function.

---

# 9. Friend Class

A class can declare another class as its friend.

```cpp
class B;

class A {
private:
    int x = 10;

    friend class B;
};

class B {
public:
    void show(A obj) {
        cout << obj.x;
    }
};
```

Because `B` is a friend of `A`, member functions of `B` can access private/protected members of `A`.

## Friend function vs friend class

| Friend Function | Friend Class |
|---|---|
| One function gets access | Friend class's member functions get access |
| Not a member of original class | Separate class |
| `friend void fun(...);` | `friend class B;` |
| Can access private/protected members | Can access private/protected members |

### Friendship rules

Friendship is:

- **Not automatically mutual**
- **Not automatically inherited**

If `B` is a friend of `A`, that does not automatically make `A` a friend of `B`.

# 10. Reference Variables

A reference is an **alias / another name** for an existing object or variable.

```cpp
int x = 10;
int &ref = x;
```

Now `ref` refers to `x`.

```cpp
ref = 20;

cout << x;   // 20
```

Conceptually:

```text
x   ──┐
      ├── same object
ref ──┘
```

### Important rules

A reference:

- Normally must be initialized when declared.
- Refers to an existing object.
- Is an alias rather than an independently declared object.
- Cannot normally be reseated to refer to another object.

Example:

```cpp
int a = 10;
int b = 20;

int &r = a;
r = b;
```

After this:

```text
a = 20
b = 20
```

`r` still refers to `a`; `r = b` assigns `b`'s value to `a`.

# 11. Call by Value

The function receives a **copy**.

```cpp
void change(int x) {
    x = 100;
}

int main() {
    int a = 10;
    change(a);

    cout << a;    // 10
}
```

Mental model:

```text
a = 10
 ↓ copy
x = 10
```

Changing `x` does not change `a`.

---

# 12. Call by Address

The function receives the address of the original variable, usually through a pointer.

```cpp
void change(int *x) {
    *x = 100;
}

int main() {
    int a = 10;

    change(&a);

    cout << a;    // 100
}
```

Important:

```cpp
change(&a);       // address
void change(int *x)
*x               // value at that address
```

---

# 13. Call by Reference

The function parameter is a reference to the original variable.

```cpp
void change(int &x) {
    x = 100;
}

int main() {
    int a = 10;

    change(a);

    cout << a;    // 100
}
```

Notice:

```cpp
change(a);
```

No `&` is written in the call.

---

# 14. Call by Value vs Address vs Reference

| Feature | Value | Address | Reference |
|---|---|---|---|
| Parameter | `int x` | `int *x` | `int &x` |
| Call | `fun(a)` | `fun(&a)` | `fun(a)` |
| Receives | Copy of value | Address/pointer value | Alias/reference |
| Can modify original? | No | Yes, using `*` | Yes |
| Pointer syntax | No | Yes | No |
| Null possible? | Not applicable to parameter itself | Pointer can be null | Ordinary reference is expected to refer to an object |

Mental shortcut:

```text
VALUE:
a → copy → x

ADDRESS:
a → address → x
             ↓
            *x

REFERENCE:
a ← alias → x
```

# 15. Swap Using All Three Methods

## Call by Value

```cpp
void swapValue(int a, int b) {
    int temp = a;
    a = b;
    b = temp;
}
```

Original values do not change.

## Call by Address

```cpp
void swapAddress(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}
```

Call:

```cpp
swapAddress(&x, &y);
```

## Call by Reference

```cpp
void swapReference(int &a, int &b) {
    int temp = a;
    a = b;
    b = temp;
}
```

Call:

```cpp
swapReference(x, y);
```

# 16. Recursion

**Recursion** occurs when a function calls itself.

A useful recursive function needs:

1. **Base case** — tells it when to stop.
2. **Recursive case** — moves toward the base case.

Example:

```cpp
void countDown(int n) {
    if (n == 0)
        return;

    cout << n << endl;
    countDown(n - 1);
}
```

For:

```cpp
countDown(3);
```

Execution conceptually:

```text
countDown(3)
    ↓
countDown(2)
    ↓
countDown(1)
    ↓
countDown(0)
    ↓
return
```

Output:

```text
3
2
1
```

---

# 17. Recursive Factorial

```cpp
int factorial(int n) {
    if (n == 0)
        return 1;

    return n * factorial(n - 1);
}
```

For `factorial(4)`:

```text
4 × factorial(3)
       ↓
    3 × factorial(2)
           ↓
        2 × factorial(1)
               ↓
            1 × factorial(0)
                       ↓
                       1
```

Then returns:

```text
factorial(1) = 1
factorial(2) = 2
factorial(3) = 6
factorial(4) = 24
```

---

# 18. Recursive Sum

```cpp
int sum(int n) {
    if (n == 0)
        return 0;

    return n + sum(n - 1);
}
```

```cpp
sum(5)
```

returns:

```text
5 + 4 + 3 + 2 + 1 = 15
```

---

# 19. Member Function Recursion

A member function can also call itself.

```cpp
class Math {
public:
    int factorial(int n) {
        if (n == 0)
            return 1;

        return n * factorial(n - 1);
    }
};
```

Usage:

```cpp
Math m;

cout << m.factorial(5);
```

Output:

```text
120
```

The important idea:

```text
Normal function    → can recursively call itself
Member function    → can recursively call itself
```

# 21. Recursion vs Iteration

| Recursion | Iteration |
|---|---|
| Function calls itself | Uses loops |
| Uses call stack | Usually uses loop variables |
| Can be elegant for naturally recursive problems | Often simpler for straightforward repetition |
| Can use more memory | Usually uses less call-stack memory |
| Needs a reachable base case | Needs a terminating loop condition |

# 22. Common Mistakes

### Mistake 1 — No base case

```cpp
int fun(int n) {
    return n + fun(n - 1);
}
```

No stopping condition → eventually stack overflow.

### Mistake 2 — Never reaching the base case

```cpp
int fun(int n) {
    if (n == 0)
        return 0;

    return n + fun(n + 1);
}
```

For positive `n`, the function moves away from `0`.

### Mistake 3 — Confusing address and reference

Address:

```cpp
void fun(int *x);
fun(&a);
```

Reference:

```cpp
void fun(int &x);
fun(a);
```

# 23. Combined Example

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

class Calculator {
private:
    int value;

public:
    Calculator(int v = 0) {
        value = v;
    }

    inline int square() {
        return value * value;
    }

    int factorial(int n) {
        if (n == 0)
            return 1;

        return n * factorial(n - 1);
    }

    static void show(double x) {
        cout << fixed << setprecision(2) << x << endl;
    }
};

void swapValues(int &a, int &b) {
    int temp = a;
    a = b;
    b = temp;
}

int main() {
    Calculator c(5);

    cout << "Square = " << c.square() << endl;
    cout << "Factorial = " << c.factorial(5) << endl;

    int a = 10;
    int b = 20;

    swapValues(a, b);

    cout << "a = " << a << ", b = " << b << endl;

    Calculator::show(12.3456);

    return 0;
}
```

This combines:

- Default arguments
- Inline member function
- Static member function
- Manipulators
- Reference parameter
- Recursion
- Class/member functions
- `cin`/`cout` concepts

## Core associations to memorize

```text
default argument → parameter with = value

inline            → compiler permitted to substitute inline

overloading       → same name + different parameter list

friend function   → non-member with private/protected access

friend class      → class gets access to private/protected members

reference         → alias

call by value     → copy

call by address   → pointer + & at call

call by reference → & parameter + normal call

recursion         → function calls itself + base case

scope             → where a name is accessible

manipulator       → controls/formats stream I/O
```
